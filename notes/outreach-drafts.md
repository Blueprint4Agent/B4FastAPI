## Show HN

Title: Show HN: Blueprint4Agent – A FastAPI and React starter with agent workflows

URL: https://github.com/Blueprint4Agent/B4FastAPI

I built Blueprint4FastAPI under Blueprint4Agent to give agents and developers a
shared starting point for application work. The repository includes authentication,
a pinned React frontend and typed API contracts, alongside guides, worklogs and
local Make checks that make changes easier to review.

The frontend is reviewed in its own repository before the backend updates the
pinned version. Optional email, OAuth and Stripe integrations require configuration;
the template does not certify a deployment. The README includes commands to run it
locally and screenshots of the existing interface.

I'd appreciate feedback on the first-run experience and whether the contract and
review workflow makes the template easier to adapt to a real service.
