## GeekNews

제목: 에이전트와 함께 개발하기 위한 FastAPI + React 템플릿, Blueprint4Agent

주소: https://github.com/Blueprint4Agent/B4FastAPI

에이전트와 개발자가 같은 규칙으로 작업할 수 있도록 FastAPI + React 템플릿을 만들고 있습니다.
Blueprint4Agent의 Blueprint4FastAPI이며, 인증과 타입 기반 API 계약에 개발 가이드,
작업 기록, Make 검증 절차를 함께 구성했습니다.

프런트엔드는 B4React 저장소에서 별도로 검토한 뒤 백엔드가 고정 버전을 갱신합니다.
기능이 있는 것뿐 아니라 변경한 내용과 확인한 범위를 남기는 흐름을 만들고 싶었습니다.

이메일, OAuth, Stripe는 사용할 서비스에 맞는 설정이 필요합니다. 템플릿을 가져오는 것만으로
운영 준비가 끝나는 것은 아닙니다. README에서 로컬 실행 방법과 실제 화면을 볼 수 있습니다.
처음 실행할 때 막히는 부분이나, 실제 서비스로 바꿀 때 이 구조가 도움이 되는지 피드백을 받고 싶습니다.
