# 문의하기

로그인한 사용자는 설정 → 문의하기(`/settings?section=support`)에서 텍스트 문의를 작성하고 답변을 확인합니다. 관리자는 `/admin/inquiries`에서 전체 문의를 조회하고 답변하거나 접수·처리 중·종료 상태를 변경합니다. 매니저는 본인 문의만 볼 수 있습니다. 공개 관리자 데모에는 문의 내용을 노출하지 않습니다.

`/api/v1/inquiries`는 본인 목록·작성, `/{id}`는 상세, `/{id}/messages`는 답변입니다. `/admin` 전체 목록과 `/{id}/status` 상태 변경은 관리자 전용입니다. 서버에서 작성자·관리자 권한을 검사하며 다른 사용자의 ID는 404를 반환합니다. 응답은 no-store입니다. 제목은 160자, 본문은 4000자, 대화는 200개 메시지로 제한합니다. 종료 후에는 답변할 수 없고 관리자가 다시 열 수 있습니다.

작성·답변 요청 UUID로 재시도 중복을 방지하고 PostgreSQL의 사용자·문의 잠금으로 변경을 직렬화합니다. 문의와 알림을 같은 트랜잭션에서 저장한 후 기존 SSE로 갱신을 알립니다. 접수 시 작성자와 활성 관리자, 답변 시 상대방, 상태 변경 시 작성자에게 알림을 보냅니다. 이메일 설정은 필요하지 않으며 첨부파일·이메일 전달은 포함하지 않습니다.

0019 마이그레이션을 적용합니다. 계정 삭제 시 본인 문의가 함께 삭제되며, 삭제된 관리자의 답변에서는 작성자 식별자가 제거됩니다. 이미지 빌드는 자동 실행하지 않습니다.
